# Save Writing Learning

Make learning visible and scoped.

## Routing

Save to:

- `voice.md` for cross-format sentence rhythm, diction, humor, tone, and assistant tics.
- `style-guides/ops.md` for operational Slack, email, memo, policy, and handoff behavior.
- `style-guides/article.md` for Every article, Vibe Check, essay, and public writing behavior.
- `strategy/contributor-positioning.md` for recurring territory, audience promise, and article lanes.
- `context.md` for current work, provisional observations, and unapproved patterns.

## Approval Rule

If Arielle explicitly says to save a durable preference, propose exact wording and destination. Write only after she approves the wording.

If the agent merely notices a pattern, ask whether to record it or add it to `context.md` as provisional.

Never save private facts, draft phrases, Slack messages, performance data, legal/finance details, or people-sensitive context as reusable guidance without explicit approval.

## Proposed Update Format

Return:

```text
Suggested destination: <file>
Proposed wording: <exact text>
Why here: <brief reason>
Durable or provisional: <durable/provisional>
```

Then ask whether to save, revise, or leave unsaved.
