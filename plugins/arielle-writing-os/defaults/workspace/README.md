# Arielle Writing Workspace

Start small. For most writing tasks, only these files are needed:

```text
voice.md
context.md
style-guides/ops.md
style-guides/article.md
strategy/contributor-positioning.md
```

## Durable vs. Provisional

Durable files:

- `voice.md`
- `style-guides/*.md`
- `strategy/*.md`

Provisional file:

- `context.md`

Durable files change only after Arielle approves the exact wording. `context.md` can hold current project notes, recent observations, and candidate learnings.

## Precedence

For a writing task, apply:

1. User instruction.
2. Source material.
3. `voice.md`.
4. Relevant style guide.
5. Strategy file only when the task is about public positioning or recurring article lanes.
6. `context.md` for current work and provisional observations.

Immediate user instructions can override style for one piece. They do not silently rewrite durable guidance.
