# every-thing

Personal and ops skills for Arielle Shipper.

## Skills

- `skills/arielle-email-writer`: Draft and revise emails in Arielle's voice.
- `skills/arielle-operating-system`: Adapt planning, recommendations, and decision support to Arielle's operating style.
- `skills/commission-plan-review`: Review sales commission plans, side letters, SIPs, and comp exhibits.
- `skills/every-ops-context`: Use Every-specific tool, approval, and handoff context.
- `skills/inbox-slack-triage-style`: Triage Gmail, Slack, Notion, and related work requests into useful action buckets.
- `skills/ops-dispute-negotiation`: Resolve vendor pushback, disputed invoices, ops escalations, and legal-adjacent negotiation questions.
- `skills/procurement-pricing-modeler`: Model vendor procurement decisions, compare pricing structures, and prepare negotiation-ready scenarios.

## Plugins

- `plugins/arielle-writing-os`: Private Codex/Claude writing plugin for Arielle's Every-style ops writing, article development, editorial review, and visible writing memory.

## Sync To Codex

The folders under `skills/` are the source of truth. To make Codex discover them across sessions, link each skill folder into `~/.codex/skills/`.

## Plugin Marketplace

Repo-local plugins are listed in `.agents/plugins/marketplace.json`.
