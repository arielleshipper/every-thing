# every-thing

Personal, ops, writing, marketing, and workflow skills for Arielle Shipper.

## Source Of Truth

This repo is the durable source of truth for Arielle-specific Codex skills and related personal workflow context. The `skills/` directory should mirror the custom skills installed in `~/.codex/skills/`, excluding Codex system skills, temporary sync backups, and third-party plugin cache contents.

When a skill or personal operating-context file is updated locally, the closeout step is:

1. Give Arielle a chance to review the change when it affects future behavior, voice, approvals, money, access, legal, or external communication.
2. Commit the reviewed update in this repo.
3. Push it to GitHub so future Codex sessions inherit the same source of truth.

## Skills

The `skills/` folder mirrors the custom skill set currently available to Codex, including:

- Arielle operating style, email voice, Slack triage, presentation comms, self-improvement, and Codex-level-up nudges.
- Every ops context, procurement modeling, vendor dispute negotiation, SaaS renewal negotiation, commission-plan review, and weekly ops update workflows.
- Ramp and finance workflows for approvals, bills, procurement, payments, receipts, reimbursements, spend analysis, transactions, vendor docs, agentic purchasing, and Ramp applications.
- Brand, positioning, launch, messaging, marketing science, copywriting, editing, email, social, web, naming, and press-comms skills.
- Browser automation, deck handling, and flight-search helper skills.

## Plugins

- `plugins/arielle-writing-os`: Private Codex/Claude writing plugin for Arielle's Every-style ops writing, article development, editorial review, and visible writing memory.

## Sync To Codex

The folders under `skills/` are the source of truth. To make Codex discover them across sessions, link each skill folder into `~/.codex/skills/`.

If a skill exists in `~/.codex/skills/` but not here, copy it into this repo before relying on it as durable Arielle context. If a skill is generated by a plugin or belongs to Codex itself, do not vendor it into this repo unless Arielle explicitly wants to fork or personalize it.
