# Arielle Slack Send Hard Gate

Before any Slack draft, send, post, reply, DM, edit, attachment handoff, or share on Arielle's behalf:

1. Load `inbox-slack-triage-style` in the current turn before composing or calling a Slack write tool.
2. Read the destination's live context and identify whether it is a DM, group DM, thread, channel post, or handoff.
3. For access, people, security, money, legal, vendor, customer, or external-commitment messages, show Arielle the exact text and wait for her approval unless she supplied the exact wording and explicitly asked to send it.
4. Immediately before sending or editing, run the skill's literal-text, sender-perspective, and no-report-shaped-Slack checks.
5. If any step is missing, do not send or edit.
